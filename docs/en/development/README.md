# Development Standards

This directory contains the documents needed to run collaborative development in a predictable way.

## Read these before contributing

1. [`contributing.md`](contributing.md)
2. [`../architecture/README.md`](../architecture/README.md)
3. [`../adr/README.md`](../adr/README.md)

## Standards covered here

- contribution workflow
- review expectations
- documentation update rules
- when to write ADRs
- when to write specs

## Scope

These standards apply to the new implementation under [`../../../src/`](../../../src/) and to shared documentation. The `legacy/` codebase can still be referenced, but it should not be the default place for new design decisions.
