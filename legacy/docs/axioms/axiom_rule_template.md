## 対象

## 使う順位

- 土台の弱順序: `rank` 列（`A ≽ B` ⇔ `rank(A) <= rank(B)`）
- 相互作用/貢献側: `rank_*` 列（`T P^I S` ⇔ `rank_*(T) < rank_*(S)`）

## 判定条件（Antecedent / Consequent）

- Antecedent:
  - 箇条書きで条件を定義
- Consequent:
  - 箇条書きで結論を定義

## 欠損値・skip

- 必要行が欠損している場合の skip 条件を明記

## 計算量
