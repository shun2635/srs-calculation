# credit_g（Credit Risk / German Credit）

`game_table.csv` は、特徴量のサブセット（提携）ごとに学習→評価した `accuracy` を並べたテーブルです。
このリポジトリでは「特徴量＝プレイヤー」とみなして協力ゲーム化し、`real-gen` でランキングルールを適用します。

## 重要: 提携集合（10特徴量版）

この `game_table.csv` は 10 特徴量の提携集合（基本的に `2^10-1`）を持ちます。
空集合（全ゼロ行）は存在しないため、`schema.yaml` の `empty_score` を用いて取り込み時に補完します（= 完全テーブルとして扱う）。

特徴量の対応（順序・表示名・説明）は `schema.yaml` に明示しています（bridge データセット方式）。
